# AutoChessTactics

给《杀戮尖塔 2》加入自走棋式的金币、商店和卡牌合成玩法。

## 功能

- 每完成一个房间，按当前金币比例获得利息。
- 商店增加刷新按钮，可重新随机卡牌、遗物和药水。
- 牌组界面增加合成按钮，两张同名同星级卡可合成为更高星级。
- 二星卡按一星基础数值的 1.5 倍计算，三星卡按 3 倍计算，小数向下取整。
- 升级状态会保留，充能球、召唤、选择、牌组结构和状态类卡牌按各自规则处理。
- 相同附魔的卡牌可以合成，并保留附魔。
- 在 Mod 管理界面中可设置利息率、合成费用、刷新费用和商店删牌是否免费。
- 合成卡的星级和数值会随存档保存，并在战斗、事件和复制流程中保留。

## 设置

打开游戏的 Mod 管理界面，找到 `AutoChessTactics`，点击“自走棋设置”：

- 利息率：`0%` 到 `100%`
- 合成费用
- 商店刷新费用
- 商店删牌免费开关

设置修改后立即保存。
