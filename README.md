# AutoChessTactics

给《杀戮尖塔 2》加入一套自走棋玩法。

## 玩法

- 房间结束后按金币获得利息。
- 商店可以花金币刷新卡牌、遗物和药水。
- 两张同名同星级卡可以合成更高星级，升级状态和相同附魔会保留。
- 二星卡按一星数值的 1.5 倍计算，三星卡按 3 倍计算。
- 充能球、召唤、牌组变化和特殊效果卡会保留原本的使用方式。

## 设置

在 Mod 管理界面找到 `AutoChessTactics`，打开“自走棋设置”：

- 利息率：`0%` 到 `100%`
- 合成费用
- 商店刷新费用
- 商店删牌是否免费

设置会自动保存。
